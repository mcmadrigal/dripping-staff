Google Sheet Setup

Connect your staff data in 4 steps.
Step 1 — Create the Google Sheet

Create a new Google Sheet. Add the following tabs — tab names must match exactly (lowercase, underscores).

Tab: _config

Two columns: key and value

  • festival_name
  • dates
  • venue_name
  • venue_address
  • hotel_name
  • hotel_address
Tab: _contacts

Emergency contacts shown on every staff page.

Columns: name, role, phone, hours, is_whatsapp

Set is_whatsapp to whatsapp for WhatsApp numbers. Leave blank otherwise.

Tab: _teams

One row per team.

Columns: team_id, team_name, type, icon, captain_name, captain_phone

  • type = team — one shared page for the whole team
  • type = individual — each person gets their own page
  • team_id must match the data tab name exactly
  • icon = any emoji
Team data tabs (type = team)

Create a tab named after the team_id (e.g., check_in).

Columns: section, content

Each row = one section on the page, rendered top to bottom.

  • Use Alt+Enter for line breaks within a cell
  • Start lines with - for bullet points
  • Use **text** for bold
  • Phone numbers auto-link for tap-to-call
  • Use time | detail format for schedule rows
  • Start section name with ⚠️ for alert styling
Individual data tabs (type = individual)

Create a tab named after the team_id (e.g., archival).

Columns: person_id, name, phone, role, section, content

  • First row for each person: fill in name, phone, role
  • Additional rows: only person_id + section + content needed
  • Use person_id = _shared for content shown on everyone's page
  • person_id = lowercase with underscores (e.g., sam_clarke)
Step 2 — Publish the Sheet
  • File → Share → Publish to web → Entire Document → CSV → Publish
  • Also: Share → Anyone with the link → Viewer
Step 3 — Connect

Find your Sheet ID in the URL:

docs.google.com/spreadsheets/d/[SHEET_ID]/edit

  • Visit the admin hub and click "Connect Google Sheet"
  • Or add ?sheet=SHEET_ID to any portal URL
Step 4 — Share with staff

Send each team their direct link. Staff only see their own page — no navigation to other teams.

  • Team pages: team.html?id=check_in
  • Individual pages: person.html?team=archival&id=sam_clarke

Staff can add to iPhone home screen (Share → Add to Home Screen) for app-like access.

Updating content

Edit the Google Sheet — changes appear within minutes. Staff can tap Refresh at the bottom of any page. Pages also work offline after first load.
